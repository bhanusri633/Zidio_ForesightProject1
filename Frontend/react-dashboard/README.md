# 📊 Sales Forecasting Dashboard (Frontend)

This is the React frontend for the AI Sales Forecasting Dashboard.

## 🚀 Features

- Dashboard Overview
- Analytics
- Sales Prediction
- Interactive Charts
- Product Search
- Export PDF
- Export Excel
- Responsive Design

## 🛠 Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- Axios
- React Router

## ▶ Run the Project

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```
